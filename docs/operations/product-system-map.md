# HotelsVendors Product System Map

## Core proposition
HotelsVendors is a four-sided hospitality network for **Hotels, Suppliers, Carriers, and Funders**. Its operating value is to turn real hospitality network signals into procurement savings, working-capital/referral opportunities, and measurable outcomes.

The core loop is:

`REAL NETWORK DATA → SIGNAL → ANALYSIS → OPPORTUNITY → PROCUREMENT / REFERRAL ACTION → OUTCOME → MEASUREMENT`

The **Virtual Shadow** is the intelligence layer that continuously observes the network context and surfaces money leaks, supplier opportunities, procurement opportunities, operational risks, and funding signals. It does not lend money itself.

## Product categories
- **Procurement:** catalog, sourcing, RFQ, quotation comparison, cart, checkout, orders, invoices, receiving.
- **Money Leak / Savings Intelligence:** spend, benchmarks, findings, evidence, opportunities, savings reports, smart fixes.
- **Supplier Network:** supplier onboarding, catalog, inventory, orders, ratings, supplier analytics.
- **Logistics:** carriers, routes, trips, shipments, delivery, ETA, GRN and proof-of-delivery flows.
- **Capital Signals:** cashflow, eligibility, factoring/referral bridges, credit lines, funder workspace. HV is not the lender.
- **Compliance:** ETA e-invoicing, VAT checks, KYC, audit trail, authority rules.
- **Virtual Shadow:** discovery, sources, entities, graph, findings, opportunities, actions, monitoring and evidence.
- **Operations/Admin:** tenant management, permissions, audit, controls, retries, reporting and platform health.

## Revenue boundaries
HV can monetize procurement transactions, subscriptions/services, savings outcomes and qualified partner referrals. Capital providers make financing decisions and fund transactions externally.
