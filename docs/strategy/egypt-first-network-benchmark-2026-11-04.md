# Egypt-first HotelsVendors network benchmark

## Decision

HotelsVendors is a neutral hospitality procurement network and operating-data
layer. It is not a supplier, funder, carrier, or generic catalogue.

Phase 1 optimizes for Egyptian hotel adoption, verified local supply, demand
aggregation, and an auditable request-to-settlement workflow. Global platforms
are reference points only; a capability is adopted now only when it solves an
Egyptian operating problem and fits local tax, data, payment, language, and
partner constraints.

## Transferable benchmark patterns

- Hospitality procurement suites: supplier/product master data, property-level
  purchasing, contract-rate enforcement, RFQ review, and centralized spend.
- Restaurant operations platforms: inventory/par levels, price-change alerts,
  receiving discrepancies, invoice/AP automation, mobile workflows, and
  multi-unit cost intelligence.
- Enterprise procurement networks: supplier participation, invoice exchange,
  analytics, early-payment boundaries, and network effects.
- Egyptian hospitality hubs: local supplier reach, industry relationships, and
  channel access that can accelerate verified onboarding.

## HotelsVendors moats for Phase 1

1. Verified Egyptian supplier/provenance graph.
2. Aggregated hotel demand and purchasing intelligence.
3. Supplier-neutral sealed RFQ and negotiation workflow.
4. Contract-price, delivery, and variance controls.
5. Receiving evidence and order/invoice reconciliation.
6. ERP, accounting, PMS, and ETA integration adapters.
7. Arabic/English, EGP, VAT, tax-ID, and e-invoice-ready records.

## Implementation rule

Every benchmark-derived feature must be classified as adopt, adapt, defer, or
reject, with a source, Egypt fit assessment, measurable outcome, and security/
tenant impact. No proprietary code or private system behavior is copied.

## Phase 2 boundary

Global expansion starts only after Egypt demonstrates repeat hotel demand,
verified supplier activity, successful lifecycle completion, reliable fulfilment,
and sustainable unit economics.
