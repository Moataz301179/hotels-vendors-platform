### Migration-parity & production-readiness findings (G5 / G2 / G6)

Corrective action taken (isolated CI DB only): re-provisioned `hv_e2e` via `db push`, then installed the append-only audit trigger as DDL. Verification: `tests/integration/procurement-lifecycle.spec.ts` → **6/6 passed**. Recommended follow-up: convert the SQLite-era migration SQL to PostgreSQL types and run `prisma migrate deploy` as the canonical CI path.
